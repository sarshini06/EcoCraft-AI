# EcoCraft AI

## Overview
EcoCraft AI is an AI-powered waste classification and upcycling system developed using Python. It classifies waste images and suggests eco-friendly recycling and upcycling ideas.

## Features
- Waste image classification
- AI-powered upcycling suggestions
- Eco Score calculation
- PDF report generation
- User-friendly interface

## Technologies Used
- Python
- Streamlit
- TensorFlow/Keras
- Pandas
- Pillow
- FPDF

## How to Run
1. Install the required libraries.
2. Run:
   streamlit run app.py
